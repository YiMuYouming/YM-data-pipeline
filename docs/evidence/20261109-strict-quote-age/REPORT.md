# 严格自然时间报价时效修复

2026-11-09。修复已通过独立规格、代码质量复审及主线程最终离线验证；真实时段运行样本另验。由天元验收发现的午休计龄差异触发，本次只增加显式严格调用，不改变默认消费者。

## 行为

- 公共`query("stock_snapshot", codes=[...], quote_age_policy="wall_clock", max_quote_age_seconds=180)`按自然秒判断；阈值由调用方现有配置传入。两参数成对、仅该intent接受，非法参数在provider前拒绝。
- 主源、既有逐码补齐、整批后备及最终返回前均执行相同要求：完整源日期时间、当天、非未来、年龄不超过阈值。缺源或补不齐明确留缺口，不把午休扣时用于严格调用。
- 现有StockToday adapter仅在内部严格标记下保留实际选中的源时间原文，防止宽松正规化先补秒或掩盖非法分隔。远端请求仍只收到原参数；默认adapter输出保持原语义。
- 源时点保留精度，行年龄、`data_as_of`和freshness一致。后备等待后再核时效，最终补齐集合只列实际保留行，保留真实attempt及剔除原因。
- 无新增provider、缓存、数据库表、依赖或交易能力；不修改认证、真实缓存/行情事实和其它消费者配置。
